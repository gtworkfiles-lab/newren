\# Design Tokens



\## Typography

\- Headings: Manrope

\- Body / UI: Inter



\## Color hierarchy

\- green-first

\- blue-second

\- light warm / soft neutral backgrounds

\- warning color only functional

\## UI intent

\- calm

\- safe

\- structured

\- human

\- professional

\- non-judgmental



\## Rules

\- Primary CTA = green

\- Secondary/info actions = blue

\- Warning accent only for functional warning/error use

\- No aggressive or flashy visual emphasis
